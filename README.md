# QAOA MIS Simulations

This repository contains code and cluster submission scripts for running QAOA simulations for MIS problem on pennylane.amdgpu

## 📁 Structure

```text
├── docs/                   # Documentation and cluster cheat sheets
├── scripts/                # main.py and Slurm job submission scripts
├── src/                    # Core Python library and modules
├── data/                   # Raw stored data (untracked by Git)
├── results/                # Plots and figures (untracked by Git)
├── test/                   # Test files for the cluster
└── requirements.txt        # Python dependencies
```
